# NoBrokerage Chat - RAG Property Search System

A ChatGPT-style property search application using RAG (Retrieval Augmented Generation) with Python data processing, Node.js backend, and React frontend.

## 🏗️ Architecture

- **Python RAG**: Process CSV files and generate JSON database
- **Node.js Backend**: Express API with Hugging Face integration
- **React Frontend**: Dark-themed ChatGPT-style UI
- **Database**: Local JSON file (generated from CSVs)

## 🚀 Setup Instructions

### 1. Python RAG Setup (Run First)

```bash
cd python-rag
pip install -r requirements.txt
python process_data.py
```

This will:
- Read the 4 CSV files from `../data/`
- Merge and process property data
- Generate `../backend/properties.json`

### 2. Backend Setup

```bash
cd backend
npm install
cp .env.example .env
# Edit .env and add your Hugging Face token (already included in .env.example)
npm start
```

Server runs on: http://localhost:5000

### 3. Frontend Setup

```bash
cd frontend
npm install
npm start
```

App opens at: http://localhost:3000

## 🎯 Features

✅ **RAG-based Search**: Python processes CSVs → JSON database  
✅ **Intent Detection**: Distinguishes property vs general queries  
✅ **Smart Filtering**: BHK, city, budget, status extraction  
✅ **City Validation**: Only shows properties in available cities  
✅ **AI Fallback**: Hugging Face API for non-property questions  
✅ **Dark Theme**: ChatGPT-inspired UI  
✅ **No Hardcoding**: All data from CSV files

## 🐛 Troubleshooting

**Problem**: `properties.json` not found  
**Solution**: Run Python script first: `cd python-rag && python process_data.py`

**Problem**: Backend not connecting  
**Solution**: Make sure backend is running on port 5000

**Problem**: CORS errors  
**Solution**: Backend has CORS enabled for localhost:3000

## 📦 Deployment

1. Generate JSON: `python python-rag/process_data.py`
2. Build frontend: `cd frontend && npm run build`
3. Deploy backend + frontend build folder to hosting service
